# Online Quiz Application

A modern, single-page desktop quiz application built with Java Swing. This project features a completely custom, unified graphical interface (using `CardLayout`) to seamlessly transition between login, registration, quiz selection, and results without opening multiple windows.

## ✨ Features

* **Modern User Interface:** Clean, spacious design featuring a custom color palette, borderless components, and smooth hover animations.
* **Single-Window Architecture:** Utilizes `CardLayout` to feel like a modern web app, completely eliminating disruptive popup frames.
* **User Authentication:** Built-in Registration and Login system to secure access to the quizzes.
* **Multiple Subjects:** Includes interactive, 5-question quizzes for:
  * Java
  * Python
  * C++
* **Instant Feedback & Scoring:** Tracks progress question-by-question and generates a final score screen upon completion.

## 🛠️ Technologies Used

* **Language:** Java
* **UI Framework:** Java Swing & AWT (Abstract Window Toolkit)
* **Architecture:** Event-Driven Programming, Object-Oriented Design
